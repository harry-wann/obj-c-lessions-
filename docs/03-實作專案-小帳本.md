# 03 實作專案：小帳本（LittleBook）

> 一支簡單但完整的記帳 App。每個模組的 Xcode 任務都是它的一塊，做完模組 10 就是成品。
> 選記帳而不是待辦清單的理由：金額（`NSDecimalNumber`）、日期、分類階層、月結統計、復原、網路匯率，剛好把課程要教的東西都用上，而且資料結構出場得很自然。

---

## 1. 功能規格

| 畫面 | 功能 | 對應章節 |
|---|---|---|
| **交易列表** | 依月份分 section；每列顯示分類圖示、備註、金額（支出紅 / 收入綠）；section header 顯示該月收支合計；滑動刪除；導覽列「復原」「新增」 | 8.4、5.5 |
| **新增 / 編輯交易** | 金額（數字鍵盤）、種類（支出 / 收入 分段控制器）、日期（`UIDatePicker`）、分類（進入分類選擇頁）、備註；儲存 / 取消；鍵盤遮擋處理 | 8.5、8.6 |
| **分類選擇** | 樹狀分類以縮排顯示（食 → 早餐 / 午餐 / 晚餐；交通 → 捷運 / 計程車 …）；可展開收合 | 8.4 ＋ 樹 |
| **統計（Swift 撰寫）** | 本月支出 / 收入 / 結餘；依分類加總的長條；數字隨帳本 KVO 即時更新 | 10.1、6.4、8.8 |
| **匯率換算** | 編輯頁可切換幣別，從網路取匯率換算成主幣別；離線用上次快取；失敗顯示錯誤 | 7.6、7.7 |
| **設定** | 主幣別、是否顯示小數、清除全部資料（確認對話框）、匯出 JSON | 9.2、8.6 |
| **持久化** | 關閉重開資料仍在；JSON 檔原子寫入；背景寫入 | 9.4 |

不做：登入、雲端同步、多帳本、預算提醒（列為選讀延伸）、Widget、iPad 專屬排版。

## 2. 架構

簡單的 MVC ＋ 一層服務（service），刻意不引入 MVVM / 第三方庫，因為工作上碰到的 ObjC 專案多數就是這個樣子。

```
Models/        LBTransaction  LBCategory  LBRate  LBMonthSection
Core/          LBLedger（帳本：資料與邏輯）  LBUndoStack  LBSettings
Services/      LBPersistence  LBRateService  LBSyncQueue
Collections/   LBLinkedList  LBLRUCache  LBHashMap  LBPriorityQueue（選）
Categories/    NSDecimalNumber+LBFormatting  NSArray+LBFunctional  NSDate+LBMonth
ViewControllers/
               LBTransactionListViewController
               LBTransactionEditorViewController
               LBCategoryPickerViewController
               LBSettingsViewController
               StatsViewController.swift        ← 唯一的 Swift 檔
Views/         LBTransactionCell  LBMonthHeaderView  LBBarChartView
Support/       LBTypes.h  LBConstants.h/.m  AppDelegate  SceneDelegate  main.m
Tests/         每個 Core / Services / Collections 類別一個 XCTestCase
```

## 3. 資料模型

```objc
// LBTransaction（不可變，NSCopying）
NSUUID *identifier
NSDecimalNumber *amount           // 永遠為正，方向由 kind 決定
LBTransactionKind kind            // NS_ENUM：LBTransactionKindExpense / Income
NSDate *date
NSString *note                    // copy
LBCategory *category
LBTransactionFlags flags          // NS_OPTIONS：Reconciled / Recurring

// LBCategory（樹節點）
NSString *identifier, *name, *symbolName
LBCategory *parent                // weak  ← 4.3 的教材
NSArray<LBCategory *> *children   // strong，對外不可變
- (NSUInteger)depth;  - (NSArray<LBCategory *> *)flattened;  // 遞迴走訪

// LBLedger（可觀察）
NSArray<LBTransaction *> *transactions           // readonly，對外不可變，內部 NSMutableArray 依日期倒序
NSDecimalNumber *total                           // KVO-compliant
id<LBLedgerObserver> delegate                    // weak
- addTransaction: / removeTransactionWithIdentifier: / replaceTransaction:with:
- transactionsGroupedByMonth → NSArray<LBMonthSection *>
- totalForKind:inMonth:
- transactionWithIdentifier:                     // 內部用 NSDictionary 索引
```

## 4. 資料結構對應

| 需求 | 自己實作（練習） | 之後換成 | 章節 |
|---|---|---|---|
| 依 ID 快速找交易 | `LBHashMap` | `NSMutableDictionary` | 3.4 |
| 格式化字串快取 | `LBLinkedList` + `LBLRUCache` | `NSCache`（比較行為差異：NSCache 會自動清） | 4.3–4.4 |
| 復原 / 重做 | `LBUndoStack`（雙堆疊，動作用 block 封裝） | `NSUndoManager`（比較） | 5.5 |
| 離線待同步 | `LBSyncQueue`（FIFO，串列佇列保護） | `NSOperationQueue` | 7.4 |
| 分類階層 | `LBCategory` 樹 ＋ 遞迴 `flattened` | — | 8.4 |
| 新交易插入位置 | 手寫二元搜尋 | `indexOfObject:inSortedRange:options:usingComparator:` | 8.4 |
| 預算提醒（選） | `LBPriorityQueue`（二元堆積） | — | 7.7 |

每個里程碑一個資料夾：`xcode/M0x-starter`（含失敗的測試）與 `xcode/M0x-solution`。starter 內已放好下一步要用的空殼與 `// TODO:`，讓你專注在當章主題。

| 里程碑 | 完成後 App 的樣子 | 通關條件 |
|---|---|---|

| M2 | `LBTransaction` / `LBCategory` 完整 model | `LBTransactionTests`、`LBCategoryTests` 全綠 |
| M3 | `LBLedger` 核心邏輯；`LBHashMap` | `LBLedgerTests`、`LBHashMapTests` 全綠 |

## 6. 測試策略

- 核心邏輯（Models / Core / Services / Collections）**全部有單元測試**，UI 層只做手動驗收清單（UI 測試對學習 ObjC 幫助小、成本高）。
- 每個 Xcode 任務的通關條件就是「指定的測試檔全綠」，網站上的任務卡列出測試名稱。
- 網路以 stub 檔取代，測試不打網路；持久化測試寫到 `NSTemporaryDirectory()`。
- 記憶體洩漏用「建立物件 → 弱參考 → 釋放 → `XCTAssertNil(weakRef)`」的樣板驗證。
