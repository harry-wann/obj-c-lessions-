## 每日複習機制

- 首頁「今日複習」自動從錯題池與前兩天的小測驗抽 5 題（簡單間隔重複）。
- 每個模組結束有「模組總測」10 題，低於 7 題就建議隔天再做一次。
- 第 7 天與第 14 天各有一次「資料結構 ＋ 記憶體管理」綜合測。

## 進入工作前的最後檢查（第 14 天）

- [ ] 能不看文件寫出：類別宣告、指定初始化器、`copy` 屬性、協定、分類、block typedef、weakSelf 樣板、GCD 回主執行緒、`NSError **` 方法。
- [ ] 看到 `unrecognized selector` / `EXC_BAD_ACCESS` / `index beyond bounds` / `not key value coding-compliant` / `mutated while being enumerated` 五種訊息能在 30 秒內說出可能原因。
- [ ] 能解釋：ARC 怎麼運作、為什麼 delegate 要 weak、`atomic` 為什麼不是執行緒安全、分類與延伸的差別、`+load` 與 `+initialize` 的差別。
- [ ] 能在 Swift 檔案呼叫 ObjC 類別，並說出 nullability 對 Swift 端的影響。
- [ ] 能打開一個陌生的 ObjC 專案，從 `AppDelegate` 與 `Podfile` 開始，30 分鐘內畫出主要畫面與類別關係。
