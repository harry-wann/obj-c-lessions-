> 全站以**台灣**用語為主，首次出現時附英文原文。本表同時列出中國大陸常見用語，方便你讀簡體技術文章或與對岸同事溝通。
> 標 ★ 的詞兩岸差異大，最容易混淆。

## 寫作規範（給內容撰寫者）

1. 以台灣用語為主；首次出現附英文：「協定（protocol）」。之後可只寫中文或只寫英文（業界常直接講的詞：delegate、block、selector、cell、crash、runtime）。
2. API 名稱、關鍵字、檔名一律用原文與等寬字：`@property`、`dealloc`、`NSArray`。
3. 不用「對象」「数组」「内存」等對岸用語於正文；對照表除外。
4. 避免機翻腔：不寫「進行一個初始化的動作」，寫「初始化」；不寫「被呼叫」堆疊式被動，能主動就主動。
5. 標點用全形「，。：；（）」，英數與中文之間留半形空格。
