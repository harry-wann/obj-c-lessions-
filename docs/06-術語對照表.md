# 06 術語對照表（台灣 / 中國大陸 / 日本）

> 全站以**台灣**用語為主，首次出現時附英文原文。本表同時列出**中國大陸**與**日本 IT 界**常見用語，方便你讀簡體技術文章、日文技術文件（Qiita、Zenn、Apple 日文文件）或與對岸、日本同事溝通。
> 標 ★ 的詞三方差異大，最容易混淆。日文以片假名外來語為主時，括號內附常見漢字寫法。

## 寫作規範（給內容撰寫者）

1. 以台灣用語為主；首次出現附英文：「協定（protocol）」。之後可只寫中文或只寫英文（業界常直接講的詞：delegate、block、selector、cell、crash、runtime）。
2. API 名稱、關鍵字、檔名一律用原文與等寬字：`@property`、`dealloc`、`NSArray`。
3. 不用「對象」「数组」「内存」等對岸用語於正文；對照表除外。
4. 避免機翻腔：不寫「進行一個初始化的動作」，寫「初始化」；能主動就不用被動。
5. 標點用全形「，。：；（）」，英數與中文之間留半形空格。
6. 日文對照僅出現在術語表與各章「術語」小卡的收合區，不進正文。
