## C. 補充進去的東西（你沒提但我認為必要）

1. **💥 崩潰現場**：每章一則真實 crash 訊息的解讀；速查區另有「崩潰訊息排查表」。
2. **偵錯工具（12.4）**：Exception Breakpoint、Zombie、Memory Graph、Sanitizer、Analyze、符號化 crash log。
3. **訊息派送與 runtime（M6）**：面試必考，也是理解一半以上 crash 的鑰匙。
4. **Swift ↔ ObjC 邊界資訊丟失（12.1、12.2）**：混編專案最常見的 bug 來源。
5. **金額用 `NSDecimalNumber`**：順便教「為什麼不能用 double 算錢」。
6. **間隔複習**：首頁每天 5 題錯題池。
7. **符號快捷列**：手機鍵盤打 `[]^@` 很痛苦，練習輸入框上固定一列符號。
8. **寫作規範（06 末段）**：避免機翻腔的具體規則。
9. **四語言對照總表（02 附錄 B）**。
10. **上工檢查表與 20 題面試題（12.6）**。
11. **程式碼風格與 clang-format（12.5）**。
12. **效能驗收有數字（03 §2）**：FPS、單幀耗時、記憶體峰值、執行緒數、TSan 零警告，不然「不掉幀」只是口號。
13. **`-ObjC` 連結旗標與 category 消失（11.6）**：老專案最經典的 crash，面試也常考。
14. **`LittleBook-Legacy` 埋雷版**：讀修真實的老派程式碼，比只讀課文有效。
15. **日文職場高頻詞**（仕様、不具合、工数）放進 06，若你有日本客戶或同事會用到。

## D. 刻意不做的事（避免範圍膨脹）

- 不做帳號系統、留言 / 社群功能。
- 不做 UI 自動化測試。
- 不深入 Core Data、Core Animation、Metal、推播、上架流程。
- 不教 Objective-C++（`.mm`）細節。
- 不做 iPad 專屬排版。
- Figma 不做互動原型（prototype 連線），導覽流程以流程圖呈現。
