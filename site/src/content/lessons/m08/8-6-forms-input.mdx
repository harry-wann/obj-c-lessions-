## Objective-C 怎麼寫

### UITextField 與 UITextFieldDelegate

```objc
// LBTransactionEditorViewController.m（節錄）
- (void)viewDidLoad {
    [super viewDidLoad];
    self.title = self.editingTransaction ? @"編輯交易" : @"新增交易";

    self.amountField = [UITextField new];
    self.amountField.placeholder = @"0.00";
    self.amountField.keyboardType = UIKeyboardTypeDecimalPad;   // 只有數字與小數點
    self.amountField.font = [UIFont monospacedDigitSystemFontOfSize:34
                                                             weight:UIFontWeightSemibold];
    self.amountField.textAlignment = NSTextAlignmentRight;
    self.amountField.delegate = self;
    [self.amountField addTarget:self
                         action:@selector(amountChanged:)
               forControlEvents:UIControlEventEditingChanged];

    self.navigationItem.leftBarButtonItem =
        [[UIBarButtonItem alloc] initWithBarButtonSystemItem:UIBarButtonSystemItemCancel
                                                      target:self
                                                      action:@selector(cancelTapped)];
    self.navigationItem.rightBarButtonItem =
        [[UIBarButtonItem alloc] initWithBarButtonSystemItem:UIBarButtonSystemItemSave
                                                      target:self
                                                      action:@selector(saveTapped)];
    self.navigationItem.rightBarButtonItem.enabled = NO;
    // ... 其他欄位、UIStackView 版面、放進 UIScrollView
}

#pragma mark - UITextFieldDelegate

- (BOOL)textField:(UITextField *)textField
    shouldChangeCharactersInRange:(NSRange)range
                replacementString:(NSString *)string {
    if (string.length == 0) return YES;                 // 刪除永遠允許
    NSCharacterSet *allowed = [NSCharacterSet characterSetWithCharactersInString:@"0123456789."];
    if ([string rangeOfCharacterFromSet:allowed.invertedSet].location != NSNotFound) {
        return NO;                                      // 貼上的字母擋掉
    }
    NSString *next = [textField.text stringByReplacingCharactersInRange:range
                                                             withString:string];
    return [[next componentsSeparatedByString:@"."] count] <= 2;   // 只准一個小數點
}

- (BOOL)textFieldShouldReturn:(UITextField *)textField {
    [textField resignFirstResponder];                   // Return 鍵收鍵盤
    return YES;
}

- (void)amountChanged:(UITextField *)sender {
    self.navigationItem.rightBarButtonItem.enabled = [self amountFromText] != nil;
}

- (nullable NSDecimalNumber *)amountFromText {
    NSString *text = [self.amountField.text stringByReplacingOccurrencesOfString:@","
                                                                      withString:@""];
    if (text.length == 0) return nil;
    NSDecimalNumber *n = [NSDecimalNumber decimalNumberWithString:text];
    if ([n isEqual:NSDecimalNumber.notANumber]) return nil;   // "1.2.3" 會變 NaN
    if ([n compare:NSDecimalNumber.zero] != NSOrderedDescending) return nil;
    return n;
}

- (BOOL)saveWithError:(NSError **)error {
    NSDecimalNumber *amount = [self amountFromText];
    if (!amount) {
        if (error) *error = [NSError errorWithDomain:LBErrorDomain
                                                code:LBErrorCodeUnexpectedType
                                            userInfo:@{ NSLocalizedDescriptionKey: @"金額無效" }];
        return NO;
    }
    LBTransaction *tx = [[LBTransaction alloc] initWithAmount:amount
                                                         kind:self.kindControl.selectedSegmentIndex
                                                         date:self.datePicker.date
                                                         note:self.noteField.text ?: @""
                                                     category:self.category];
    [self.delegate editor:self didSaveTransaction:tx];
    return YES;
}
```

`shouldChangeCharactersInRange:replacementString:` 在每個字輸入**之前**被問，回 `NO` 就不會進去，是過濾的地方；`UIControlEventEditingChanged` 在改完**之後**觸發，是驗證與更新按鈕狀態的地方。`decimalNumberWithString:` 收到垃圾不會回 nil，回 `NSDecimalNumber.notANumber`，一定要比對。`saveWithError:` 拆成獨立方法是為了測試：`testInvalidAmountDoesNotSave` 直接設 `amountField.text = @"abc"` 呼叫它，不用模擬點擊。

### 鍵盤：收合與遮擋

<Term en="first responder" tw="第一回應者" cn="第一响应者" jp="ファーストレスポンダ" />是目前接收鍵盤輸入的那個 view。`[field becomeFirstResponder]` 叫出鍵盤、`[field resignFirstResponder]` 收掉；不知道誰是 first responder 就對整個 view 呼叫 `[self.view endEditing:YES]`。點空白收鍵盤：

```objc
UITapGestureRecognizer *tap =
    [[UITapGestureRecognizer alloc] initWithTarget:self.view
                                            action:@selector(endEditing:)];
tap.cancelsTouchesInView = NO;      // 不然表格的列點不到
[self.view addGestureRecognizer:tap];
```

遮擋處理：表單放在 `UIScrollView` 裡，鍵盤出現時把底部 `contentInset` 加大鍵盤高度，消失時還原。通知在 `viewWillAppear:` / `viewWillDisappear:` 成對（8.2）：

```objc
- (void)viewWillAppear:(BOOL)animated {
    [super viewWillAppear:animated];
    NSNotificationCenter *nc = NSNotificationCenter.defaultCenter;
    [nc addObserver:self selector:@selector(keyboardWillChange:)
               name:UIKeyboardWillShowNotification object:nil];
    [nc addObserver:self selector:@selector(keyboardWillChange:)
               name:UIKeyboardWillHideNotification object:nil];
}

- (void)viewWillDisappear:(BOOL)animated {
    [super viewWillDisappear:animated];
    NSNotificationCenter *nc = NSNotificationCenter.defaultCenter;
    [nc removeObserver:self name:UIKeyboardWillShowNotification object:nil];
    [nc removeObserver:self name:UIKeyboardWillHideNotification object:nil];
}

- (void)keyboardWillChange:(NSNotification *)note {
    CGRect end = [note.userInfo[UIKeyboardFrameEndUserInfoKey] CGRectValue];
    CGRect endInView = [self.view convertRect:end fromView:nil];     // 視窗座標 → 自己的座標
    CGFloat overlap = MAX(0, CGRectGetMaxY(self.view.bounds) - CGRectGetMinY(endInView));
    CGFloat bottom = MAX(0, overlap - self.view.safeAreaInsets.bottom);
    NSTimeInterval duration =
        [note.userInfo[UIKeyboardAnimationDurationUserInfoKey] doubleValue];
    [UIView animateWithDuration:duration animations:^{
        self.scrollView.contentInset = UIEdgeInsetsMake(0, 0, bottom, 0);
        self.scrollView.verticalScrollIndicatorInsets = self.scrollView.contentInset;
    }];
}
```

用同一個方法處理 show 跟 hide：hide 時鍵盤的終點 frame 在螢幕外，`overlap` 算出來是 0，自然還原。iOS 15 以後也可以用 `view.keyboardLayoutGuide.topAnchor` 把底部約束直接綁在鍵盤上，不用通知；舊專案裡仍是通知寫法。

### UIDatePicker、UIPickerView、UISegmentedControl、UISwitch

全是 `UIControl` 子類別，走<Term en="target-action" tw="目標 — 動作" cn="目标 — 动作" jp="ターゲット・アクション" />：`addTarget:action:forControlEvents:` 登記「哪個物件的哪個 selector 在哪個事件時被呼叫」。這是 UIKit 比 delegate 更輕的回呼機制（5.2 比較過），一個 control 可以掛多組。

```objc
self.datePicker = [UIDatePicker new];
self.datePicker.datePickerMode = UIDatePickerModeDate;
self.datePicker.preferredDatePickerStyle = UIDatePickerStyleCompact;   // 一顆膠囊，點開才展開
[self.datePicker addTarget:self action:@selector(dateChanged:)
          forControlEvents:UIControlEventValueChanged];

self.kindControl = [[UISegmentedControl alloc] initWithItems:@[ @"支出", @"收入" ]];
self.kindControl.selectedSegmentIndex = LBTransactionKindExpense;
[self.kindControl addTarget:self action:@selector(kindChanged:)
           forControlEvents:UIControlEventValueChanged];

self.reconciledSwitch = [UISwitch new];                 // 對應 LBTransactionFlagsReconciled
[self.reconciledSwitch addTarget:self action:@selector(flagsChanged:)
                forControlEvents:UIControlEventValueChanged];
```

selector 簽名有三種合法形式：`- (void)action`、`- (void)action:(id)sender`、`- (void)action:(id)sender forEvent:(UIEvent *)event`；名字對不上就是本章的崩潰現場。`UIPickerView` 不是 `UIControl`，走 `UIPickerViewDataSource` / `Delegate`，跟表格一模一樣（`numberOfComponents`、`numberOfRowsInComponent:`、`titleForRow:`），幣別選擇用它。

### UIAlertController

```objc
- (void)confirmDeleteAtIndexPath:(NSIndexPath *)indexPath {
    UIAlertController *sheet =
        [UIAlertController alertControllerWithTitle:@"刪除這筆交易？"
                                            message:@"可以從導覽列「復原」救回來。"
                                     preferredStyle:UIAlertControllerStyleActionSheet];
    __weak typeof(self) weakSelf = self;
    [sheet addAction:[UIAlertAction actionWithTitle:@"刪除"
                                              style:UIAlertActionStyleDestructive
                                            handler:^(UIAlertAction *action) {
        [weakSelf deleteRowAtIndexPath:indexPath];
    }]];
    [sheet addAction:[UIAlertAction actionWithTitle:@"取消"
                                              style:UIAlertActionStyleCancel
                                            handler:nil]];
    sheet.popoverPresentationController.sourceView =
        [self.tableView cellForRowAtIndexPath:indexPath];      // iPad 需要錨點
    [self presentViewController:sheet animated:YES completion:nil];
}
```

`Alert` 樣式置中、可加文字欄位（`addTextFieldWithConfigurationHandler:`）；`ActionSheet` 從底部升起，iPad 上變 popover 必須給 `sourceView` 或 `barButtonItem`，不給會 crash。`Destructive` 樣式自動紅字，`Cancel` 樣式自動排最下面。`UIAlertView` / `UIActionSheet` 是模組 11 Legacy 專案裡會看到的前身。

<Pitfall title="點空白收鍵盤的手勢吃掉了表格點擊">
`UITapGestureRecognizer` 預設 `cancelsTouchesInView = YES`，加在整個 view 上之後，表格的列、按鈕全部點不到（手勢先搶走了）。設成 `NO`，或在 `UITableView` 上改用 `keyboardDismissMode = UIScrollViewKeyboardDismissModeInteractive`（跟著捲動收鍵盤，Messages 那種效果）。
</Pitfall>

<Pitfall title="鍵盤通知只註冊不移除，或用 dealloc 移除">
8.2 的規則在這裡最常被踩：`viewWillAppear:` 註冊、`dealloc` 移除 → 分類選擇頁 push 回來一次就多一個觀察者，`contentInset` 被加兩倍。成對放 `viewWillAppear:` / `viewWillDisappear:`。另一個版本：用 `addObserverForName:` 的 block 版卻沒存 token，永遠移除不了，block 還捕獲 `self` 循環（5.5）。
</Pitfall>

<Pitfall title="把 textField.text 直接丟給 decimalNumberWithString:">
`[NSDecimalNumber decimalNumberWithString:@"1,280"]` 回 `1`（遇到逗號停止），`@"abc"` 回 `NaN` 而不是 nil，`@""` 也是 `NaN`。先把千分位逗號拿掉、再比對 `NSDecimalNumber.notANumber`、再檢查大於零。顯示用的格式化字串與解析用的原始字串分開存，不要從已經格式化的畫面文字反推金額。
</Pitfall>

</Crash>

## 小結

- `shouldChangeCharactersInRange:` 在輸入前過濾，`UIControlEventEditingChanged` 在輸入後驗證；`decimalNumberWithString:` 回 `NaN` 不回 nil。
- 收鍵盤：`resignFirstResponder` / `endEditing:`；點空白手勢設 `cancelsTouchesInView = NO`。
- 遮擋：`UIKeyboardWillShow` / `Hide` 通知成對註冊移除，用 `UIKeyboardFrameEndUserInfoKey` 算重疊量改 `contentInset`；新專案可用 `keyboardLayoutGuide`。
- `UIControl` 走 target-action，selector 的冒號數要跟實作一致；`UIPickerView` 走 dataSource / delegate。
- `UIAlertController` 的 alert / actionSheet，destructive 紅字、cancel 排底，iPad 的 actionSheet 要給 `sourceView`。
